# Teacher Notes - Unit 4 conversion

## Source-to-skillmap mapping

| Skillmap activity | Unit 4 source focus | What was retained |
| --- | --- | --- |
| 4.1 Build Your First Functions | Lesson/Lab 4.1 | function definition/call, caller/control flow, code reuse, refactoring |
| 4.2 Give Functions Information | Lesson/Lab 4.2 | parameters vs. arguments, multiple parameter types concept, level function controlled by a parameter |
| 4.3 Get Information Back | Lesson/Lab 4.3 | return values, function output, card-number arithmetic idea |
| 4.4 Search an Array | Lesson/Lab 4.4 | search definition, sequential search, found/not-found cases, refactoring search into a Boolean function |
| 4.5 Unit 4 Build Challenge | Unit Project 4.5 | meaningful functions plus arrays, loops, variables, conditionals, event handlers, math, increasing difficulty and testing |
| Binary Search Challenge | Lesson/Lab 4.4 | sorted-data requirement, midpoint/range tracking, divide-in-half algorithm |

## Deliberate changes in this first build

- Student prose was shortened for the sidebar tutorial experience.
- The large Unit 4 project remains a multi-day build rather than being reduced to a short tutorial exercise.
- Binary search is placed in a separate optional path. The Unit 4 overview's central search objective is implementing sequential search; binary search is retained as deeper enrichment.
- The 52-card worksheet from 4.3 was reduced to an interactive card-number example. The full paper worksheet is not reproduced.
- The 200-word binary-search starter project from 4.4 was replaced with a smaller sorted numeric array so the first custom skillmap can be tested without importing a large external template.

## Classroom pilot questions

During the first pilot, check:

1. Do all function snippets render as Blocks?
2. Does MakeCode expose array parameters in custom functions as expected?
3. Does `Math.idiv` render to the intended integer-division block?
4. Are students comfortable moving between tutorial instructions and the Functions dialog?
5. Is the amount of text per step appropriate for an 80-minute class?
6. Should 4.1 or 4.2 be split into two nodes?
7. Should the Unit 4 project remain in the skillmap or be launched separately with a Google Doc rubric/planner?
